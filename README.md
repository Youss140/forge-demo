# FORGE

**Voir le site : [https://youss-dev-forge.netlify.app](https://youss-dev-forge.netlify.app)**

Site vitrine d'un coach sportif en force et musculation (projet de démonstration, marque fictive).

Réalisé par **Youssouf**, développeur web freelance, comme pièce de portfolio.

## Points clés

- Timeline de méthode dont la ligne se remplit au scroll
- Sélecteur de programme interactif : 3 questions, calcul de score, recommandation argumentée
- Compteurs animés et blocs de résultats chiffrés
- Grille tarifaire, FAQ en accordéon, formulaire de contact avec validation
- 3 pages : accueil, programmes, contact
- Responsive (mobile, tablette, desktop), sans framework ni étape de build

## Stack

HTML, CSS, JavaScript vanilla. Site statique, déployé sur Netlify.

## Lancer en local

Ouvrir `index.html` dans un navigateur.
